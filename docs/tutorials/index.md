# Tutorials

Tutorials walk you through a complete task from start to finish. Follow the steps in order; each one builds on the last.

1. [Explore a conference on CERN's Indico](explore-cern.md). Install the server, connect it to Claude Code, and read the ICHEP 2024 program. No Indico account needed. About 15 minutes.
2. [Build a meeting agenda](build-an-agenda.md). Add a personal token, create a test meeting, add talks and schedule them. Needs an Indico account and a category where you can create events. About 20 minutes.
